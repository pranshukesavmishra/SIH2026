The ZeroDrift Technical Pipeline

01

Physics-True Virtual World & Sensor Simulation

Simulates real SGP4 orbital orbits, Greenwood turbulence, angular vibrations, and sensor noise producing 9.2 MPx/s of realistic sky imagery.

9.2 MPx / s Imagery
02

2D CA-CFAR Sub-Pixel Centroiding

Morphological top-hat filter and Cell-Averaging CFAR extract faint point-source beacon spots from heavy stellar background clutter.

≈ 6 Candidates / Frame
03

4 Hz Blink-Signature Hard Gating

The beacon blinks at an agreed 4 Hz. Stars and sun-glints score zero and are rejected — 0 wrong-target locks across 64 Monte-Carlo runs.

0 / 64 False Locks
04

Dual-Model IMM Kalman State Estimator

Two motion models (Constant Velocity & Constant Acceleration) dynamically re-weighted every frame to track sharp maneuvering targets.

Adaptive State Tracking
05

Smith Predictor Latency Cancellation

Internal forward model predicts 40 ms ahead to cancel mount latency, keeping the 30 Hz gimbal control loop fully stable.

40 ms Delay Canceled
06

Deterministic Closed-Loop Link Closure

Runs in 8–21 ms on 2 CPU cores (no GPU/cloud required), holding median 198 µrad error to close the link 99.3% of the time (vs 14.7% open loop).

99.3% Link Closure
